# Project structure

This repository is organized into a few simple folders.

## app/

Contains the main Python modules for review analysis, sentiment detection, theme detection, and retrieval.

## data/

Stores example review datasets and generated chunk files.

## reviews-scraper/

Contains a small helper for collecting review data from a browser-based source.

## scripts/

Contains the step-by-step processing scripts used to prepare the review data and query it.

## streamlit_app.py

Starts the web interface for the app.

## requirements.txt

Lists the Python dependencies required by the project.
