# Features

## Review cleaning

The cleaning step prepares raw review data so it is easier to analyze. It removes obvious formatting issues and separates owner responses from customer reviews.

## Theme detection

The app looks for recurring topics such as service, cleanliness, food quality, and waiting times.

## Sentiment analysis

The system labels review segments as positive, negative, or neutral.

## Retrieval and grounding

The app uses search over review chunks and only answers from the retrieved evidence.

## Workflow-style outputs

When the question is action-oriented, the app can provide suggested SMS messages and operational recommendations.
