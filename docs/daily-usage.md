# Daily usage

This page explains how to use the app once it is running.

## Ask a question

Type your question into the chat box.

Examples:

- What are the most common complaints?
- What do customers think about speed of service?
- Draft a polite message to unhappy guests.

## Understand the result

The app will return a summary plus supporting details. These may include:

- overall sentiment
- recurring issues
- isolated issues
- suggested SMS messages
- operational recommendations

## Use the sample data

The repository already includes sample data in the data/ folder. You can use it to explore the app before adding your own reviews.

## Add your own review data

To use your own data, place it in a JSON file and run the processing scripts in order.
