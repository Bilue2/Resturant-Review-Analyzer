# Documentation Home

Welcome to the documentation for the Restaurant Review Analyzer.

This guide is written for people who are new to the project and want a simple, step-by-step path to getting started.

## What this documentation covers

- how to install the project
- how to set up the required services
- how to run the app locally
- how to understand the main folders in the repository
- how to fix common problems

## Start here

1. Read [getting-started.md](getting-started.md).
2. Follow [installation.md](installation.md).
3. Continue with [first-run.md](first-run.md).
4. Use [daily-usage.md](daily-usage.md) for regular tasks.
