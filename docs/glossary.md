# Glossary

- API: a way for software to talk to another service.
- Environment variable: a setting stored outside the code so it can be changed easily.
- Repository: the folder that contains the project files.
- Virtual environment: an isolated Python setup for one project.
- Streamlit: a tool for building simple web apps with Python.
- Embedding: a numerical representation of text that helps software find related content.
- Pinecone: a vector database service used for similarity search.
- Chunk: a smaller piece of a larger review.
- Grounded response: an answer that is based on the retrieved review evidence.
