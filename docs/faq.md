# FAQ

## What is this project for?

It helps restaurant teams understand customer feedback by organizing and summarizing reviews.

## Do I need to know programming?

No. This guide is written for non-technical users.

## What is an API key?

An API key is a private password that lets the app access a service such as OpenAI or Pinecone.

## Where is my data stored?

Review files are stored in the data/ folder. Search indexes are stored in Pinecone.

## Can I use this without OpenAI?

The current workflow depends on OpenAI services for the AI parts of the app.
