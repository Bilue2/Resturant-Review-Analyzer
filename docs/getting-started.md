# Getting started

This project helps you understand restaurant reviews by organizing them and turning them into useful insights.

You do not need to be a programmer to use it. You mainly need:

- Python installed on your computer
- access to OpenAI and Pinecone
- a folder of review data

## What you will do

In simple terms, you will:

1. install the software
2. add your API keys
3. run the app
4. ask questions about the reviews

## What the app can do

The app can help you:

- find common complaints
- see whether feedback is mostly positive or negative
- group reviews by theme such as food quality or speed of service
- draft follow-up messages for unhappy guests

## Before you begin

Make sure you have:

- a computer with Python 3.10 or newer
- internet access
- an OpenAI account
- a Pinecone account
